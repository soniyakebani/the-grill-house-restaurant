# 🍽️ The Grill House — Restaurant Website

A modern, responsive restaurant website built using **HTML, CSS, and JavaScript**.

The website presents **The Grill House**, a family restaurant in Nagpur, with a clean restaurant-focused design, menu cards, interactive ordering modal, and contact section.

## ✨ Features

* 🏠 Responsive restaurant homepage
* 🧭 Sticky navigation bar
* 🍝 Interactive food menu
* 🍕 Food cards with hover animations
* ➕ Add-to-order interaction
* 🛒 Quantity selector in food modal
* 📱 Responsive design for mobile, tablet, and desktop
* 📖 About section
* 📍 Restaurant contact information
* 📝 Contact/reservation form
* 🎨 Custom restaurant color palette
* ✨ Smooth scrolling
* 🖱️ Button and card hover effects

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**
* **JavaScript**
* **Google Fonts**

  * Fraunces
  * Work Sans
* **Unsplash** for food and restaurant images
